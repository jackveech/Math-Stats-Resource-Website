Random Variables

Random variables are possibly the most important concept covered in this class.

What is the definition of a random variable?
"A random variable is a function from the sample space to the real numbers."
Well, that wasn't too informative, and raises a couple (or more) questions. Namely, what is the sample space?

The sample space is the SET of all possible outcomes. That is, the collection of every possibility in an experiment.
For example, consider rolling a die once. The sample space here is clearly {1,2,3,4,5,6} as that is the set of every possible outcome.

Great. So this random variable takes something from this sample space, and gives us something in the reals. But WHAT in the reals? Whatever you like!

For example, let's let X, our new random variable, to be the number of heads you get when you roll a die twice. This random variables has RANGE {0,1,2} because you can get a head either no times, one time, or both times.

This takes us right into our next concept, which is expected value of a random variable.

Expected Value

The expected value of a random variable is exactly what it sounds like. The expected value specifically answers the following question:

If I repeat the SAME experiment n times, where n is a large number, what value does the random variable take on average?
That is, if we repeat an experiment many times, what value can we expect to get most of the time?
This is NOT to be confused with convergence in distribution, or convergence at ALL, as that has to do with completing ONE trial MANY times. More on this in STAT 269.

How do we compute this expected value, you ask? Well, it's the first moment of a random variable (more on this later in this page). To compute the first moment, we take the integral (ugh) of the pdf with x multiplied in.
Unfortauntely, for a discrete random variable (also covered later, just remember this for now), we must iterate over each possibility of the random variable with the position we are at multiplied in each iteration. Examples below because that makes no sense.

Continuous vs Discrete Random Variables

There are two types of random varibles.
DISCRETE random variables are the "simpler" kind. They take on discrete values. For example, a random variable corresponding to the rolling of a 6-sided die will always be discrete, because your outputs are limited to {1,2,3,4,...}.
When we iterate over a discrete random variable, say for expected value, we look at the possible outputs, and do NOT integrate.

CONTINUOUS random variables can take on any value in a range.

Note that continuous random variables are represented (think drawn, or worked with) by a probability density function. Discrete random variables, on the other hand, use a probability mass function.
What do these functions allow us to do? For a probability mass function, we can determine the probability that a random variables takes on that value. For example, rolling a 6-sided die once, our PMF for the random variable X representing the value we get from rolling the die would be:

P(X=1) = 1/6

P(X=2) = 1/6

P(X=3) = 1/6

P(X=4) = 1/6

P(X=5) = 1/6

P(X=6) = 1/6

The explanation here is that you have 1/6 chance of getting each value, and each is equally likely.
Of course, this relationship is not always equal, and your random variable can represent literally anything given the context of the situation.
The RANGE of a random variable is every output it can take. Think of rolling a die, as we have done many times. A likely range for a random variable might be {0,1,2,3,4,5} if those are the values it can take on.
