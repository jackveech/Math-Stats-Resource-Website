I'd hope by now you know what a vector is. However, we will cover it again to be sure because some of you are... challenged.

A vector is a quantity that has both magnitide and direction. Of course that's the basic definition, but you can think of it as something in a space pointing from one place to another. It is pointing in a certain direction with a certain overall length.

For example, a vector could be (5,5,5) and it would point from the origin (as is assumed when working with notation) all the way up 5, over 5, and... other over 5 (things get odd when describing 3d so this is what you get). The magnitude is defined in the vector like its direction is. Rather, it's found by taking the NORM of the vector. We will now move on to a very important concept: vector spaces and vector subspaces. The definition and distinction between a vector space and vector subspace is a little (a lot) silly, so let's jump into the definitions:

A vector space is a an entire, self-contained universe of vectors. You can add them together and scale them.
A vector subspace is a "smaller universe" of vectors, basically a smaller chunk of the aforementioned vector space, that must meet certain criteria, including:
- Closure under scaling
- Closure under addition (of vectors), and
- Zero vector contained (read: your space must contain the origin. A vector going from nowhere to nowhere should still go to nowhere in your vector subspace)

Span and Linear Independence are very important topics in Linear Algebra.
The notion is span is defined as follows:

The set of all linear combinations of a list of vectors 𝑣1, ... , 𝑣𝑚 in 𝑉 is called the span of 𝑣1, ... , 𝑣𝑚, denoted by span(𝑣1, ... , 𝑣𝑚).
Span relies on this thing called linear combinations. I think they're easy enough to understand so I'm introducing both span and linear combinations in the same section.
A linear combination of vectors is just the addition of the scaling of a set of vectors. Once again that makes no sense so we will give an example.
Let's let v1 = (5,5,1). Let v2 = (6,5,2). We can make a NEW VECTOR called v3 by simply combining these other two vectors which we already have. As such, let v3 be:
v3 = 2v1 + 3v2

And we can calculate what this means of course. This means v3 is equal to 2(5,5,1) + 3(6,5,2). Which is just (10, 10, 2) + (18,15,6). Which is just (28,25,8). So this linear combination of v1 and v2 just boils down to the vector (28,25,8).
With this said, let's get the notion of span all consolidated. The span of v1 and v2 is equal to:

span(v1,v2) = a*v1 + b*v2, where a and b are real constants.

So basically it's every possible way you can scale and add those two vectors. This concept is, like, unimaginably important in this course, so I beg of you to ensure that you have a deep understanding of these notions before you continue in the course.

This takes us to linear independence. A set of vectors (this is defined in the Axler book but I really hope you generally understand what I mean when I say "set of vectors") is called linearly independent if this set contains unique information. Now that literally means nothing practically, so let's consider that a little deeper.
If I have the vectors (1,0) and (0,1), are there any overlap between these vectors? Keep in mind both of these vectors live in R2, IE they have two components.
No, of course there's no overlap. Because if I get rid of any of the vectors here I lose a dimension. Now this notion of dimension doesn't exist yet for you, so we will just say if I get rid of (0,1) then that second slot no longer matters and as such the first vector can be written as just (1), because the 0 is now irrelevant.

We now move onto the concept of bases. Hold on to you hats because this is a relatively big step.
A basis for a vector space (or subspace if applicable) is a linearly independent spanning set. Great, now what does THAT mean?
We talked before about linear independence. So saying this set is linearly independent should be something you can half wrap your head around. But this set also needs to span the space. What does this mean?
It means that every possible linear combination of that set of vectors can create every possible vector in the space.
For example, if working in R2, (0,1) and (1,0) is a spanning set. This is because with any combination of these base (see where the name comes from?) vectors, you can make any vector in R2.
Let's say we want to make the vector (4,5). We can simply do 4(1,0) + 5(0,1).

Now this raises a question for some of you. Are these "bases" unique to the space? No! A basis for R2 is (0,1) and (1,0). Another possible one is (3,5) and (-2,4) (No it's not. I literally made those up, but you get my point).

Finally an easy topic. We can cover the concept of dimension pretty quickly. The dimension of a space is the number of elements in its basis. So if you can find a linearly independent spanning set for a space, count the number of vectors you used. That's the dimension of the space.
So for example the "elementary" basis for R2 is (0,1) and (1,0). There's 2 vectors. So as you can imagine, the dimension of R2 is.... 2 (and this makes sense, visualize an X and Y plane).
